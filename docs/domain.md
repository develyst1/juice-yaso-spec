# Domain rules — LOCKED

## Pricing
- ฐาน: **5 บาท/แก้ว**
- ถ้าแก้วรวมในออเดอร์ **> 100** → **4.5 บาท/แก้ว** ทั้งออเดอร์ (ไม่คิดขั้นบันได)
- `PricingConfig`: base_price_per_cup, bulk_threshold_cups, bulk_price_per_cup — แอดมินแก้ได้โดยไม่แก้โค้ด
- มีผลกับ**ออเดอร์ใหม่เท่านั้น** (ไม่แก้ย้อนหลังยอดเก่า)
- ราคาตลาดขายต่อ ~9 = นอกขอบเขต

## Crate (ลังโฟม)
- ขนาด: **30 / 50 / 60 / 100** แก้วต่อลัง
- สั่งหลายลัง / หลายขนาดในออเดอร์เดียวได้
- แก้วรวม = Σ(ขนาด × จำนวนลัง)

## Deposit (มัดจำ)
| ขนาด | มัดจำ/ลัง (บาท) |
|------|-----------------|
| 30 | 50 |
| 50 | 90 |
| 60 | 90 |
| 100 | 150 |
- มัดจำแยกจากราคาน้ำ · รวมหลายลัง
- คืนมัดจำได้เมื่อ**บันทึกคืนลังแล้ว**เท่านั้น

## Flavors
- ส้ม, องุ่น, โกโก้, ลิ้นจี่, บลูเบอร์รี่
- **ออเดอร์เดียวปนหลายรสได้**
- สีหลักแบรนด์: ส้ม

## Customer identity (v1)
- ไม่ login
- ก่อนชำระบังคับ: **ชื่อ + เบอร์** เท่านั้น
- รับที่ร้าน — ไม่เก็บที่อยู่ส่งใน v1

## Payment channel
- ลูกค้าเห็นบนบัตรคิว: **รูป QR** และ/หรือ **เลขบัญชี + ชื่อธนาคาร**
- โอนแล้วแนบสลิป · รอตรวจได้ประมาณถึง ~1 ชม.
- แอดมิน**อัปรูป QR ใหม่ / แก้เลขบัญชี / แก้ชื่อธนาคาร ได้เสมอ** (`PaymentChannelConfig`)
