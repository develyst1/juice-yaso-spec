## UC-CUS-01 สั่งจากหน้าแรก (ไม่ login)
Actor: ลูกค้า  
Main: เปิดหน้าแรก → เลือกลัง/จำนวน → เลือกรส (ปนได้) → กรอกชื่อ+เบอร์ → เห็นยอดสินค้า+มัดจำ → ยืนยัน → ได้บัตรคิวสถานะรอชำระ  
DoD: ไม่ login; บังคับชื่อ+เบอร์; ได้บัตรคิว

## UC-CUS-02 คิดราคาขายส่งและส่วนลดรวม
Rule: 5 บาท/แก้ว; >100 → 4.5 ทั้งออเดอร์; config แอดมิน; มีผลออเดอร์ใหม่เท่านั้น  
DoD: ยอดก่อนยืนยันตรงกติกา

## UC-CUS-03 คิดมัดจำลัง
Rule: ตามตารางมัดจำ · รวมหลายลัง · แยกจากราคาน้ำ  
DoD: แสดงยอดมัดจำชัด

## UC-CUS-04 ได้บัตรคิวรอชำระ
DoD: บัตรคิวอ้างอิงออเดอร์; สถานะเริ่ม = รอชำระ; ใช้ชำระ/อัปสลิป/track/ยกเลิกได้

## UC-CUS-05 ชำระด้วย QR หรือเลขบัญชี + อัปสลิป
Main: จากบัตรคิวเห็น QR/เลขบัญชี+ชื่อธนาคาร → โอน → อัปสลิป → รอตรวจสลิป  
DoD: ช่องทางชำระมาจาก config แอดมิน; อัปสลิปได้

## UC-CUS-05b อัปสลิปใหม่หลังถูกปฏิเสธ
Main: ปฏิเสธสลิป (+เหตุผล) → อัปสลิปใหม่จากบัตรคิว → กลับรอตรวจสลิป  
DoD: ทำซ้ำได้จนกว่าจะอนุมัติหรือยกเลิกตามกติกา

## UC-CUS-06 ติดตามสถานะด้วยบัตรคิว
DoD: ไม่ login ก็เห็นสถานะปัจจุบันจาก enum ที่ล็อก

## UC-CUS-07 ยกเลิกออเดอร์
Rule: ยกเลิกได้ก่อนสถานะกำลังแพ็ค  
DoD: สถานะ = ยกเลิก; เงินตาม `docs/statuses.md` (Money on cancel)

## UC-ADM-01 อนุมัติ/ปฏิเสธสลิปผ่านไลน์
Rule: reject ต้องมีเหตุผล · approve → อยู่ในคิว  
DoD: ผลสะท้อนบนบัตรคิว

## UC-ADM-02 ปรับเกณฑ์ส่วนลดรวม

## UC-ADM-03 จัดการช่องทางโอน
DoD: แอดมินอัปรูป QR + แก้เลขบัญชี + ชื่อธนาคาร ได้เสมอ
