# Customer flow (v1 pickup) — LOCKED

1. เปิดหน้าแรก (หน้าสั่ง) — ไม่ login
2. เลือกลัง/จำนวน · เลือกรส (ปนหลายรสได้)
3. กรอกชื่อ + เบอร์
4. เห็นยอดสินค้า + ยอดมัดจำ
5. ยืนยันสั่ง → ได้**บัตรคิว** สถานะ `รอชำระ`
6. บนบัตรคิว: เห็น QR และ/หรือเลขบัญชี+ชื่อธนาคาร → โอน → อัปสลิป → `รอตรวจสลิป`
7. แอดมินไลน์: approve → `อยู่ในคิว` หรือ reject(+เหตุผล) → `ปฏิเสธสลิป` (อัปใหม่ได้)
8. ร้าน: `กำลังแพ็ค` → `พร้อมรับ` → ลูกค้ามารับ → `รับแล้ว`
9. Track / ยกเลิก (ก่อนกำลังแพ็ค) ด้วยบัตรคิวตลอด

ไม่มี: ส่งของ, ดูประวัติออเดอร์เก่าโดยไม่มีรหัสบัตรคิว
