# Order statuses — LOCKED enum (v1)

| # | Status | ความหมาย |
|---|--------|----------|
| 1 | `awaiting_payment` / รอชำระ | ได้บัตรคิว ยังไม่ส่งสลิป |
| 2 | `awaiting_slip_review` / รอตรวจสลิป | อัปสลิปแล้ว รอแอดมิน |
| 3 | `slip_rejected` / ปฏิเสธสลิป | reject มีเหตุผล; อัปสลิปใหม่ได้ |
| 4 | `in_queue` / อยู่ในคิว | อนุมัติแล้ว รอแพ็ค |
| 5 | `packing` / กำลังแพ็ค | ยกเลิกไม่ได้แล้ว (~30 นาที) |
| 6 | `ready_for_pickup` / พร้อมรับ | แพ็คเสร็จ รอลูกค้ามารับที่ร้าน |
| 7 | `picked_up` / รับแล้ว | ปิดออเดอร์ |
| 8 | `cancelled` / ยกเลิก | ยกเลิกก่อนกำลังแพ็ค |

ชื่อแสดงภาษาไทยใช้ใน UI; ค่าในวงเล็บอังกฤษเป็นรหัสสัญญาแนะนำ

## Allowed transitions
```
รอชำระ → รอตรวจสลิป (อัปสลิป)
รอชำระ → ยกเลิก

รอตรวจสลิป → อยู่ในคิว (approve)
รอตรวจสลิป → ปฏิเสธสลิป (reject + reason)
รอตรวจสลิป → ยกเลิก

ปฏิเสธสลิป → รอตรวจสลิป (อัปสลิปใหม่)
ปฏิเสธสลิป → ยกเลิก

อยู่ในคิว → กำลังแพ็ค (แอดมิน/ร้าน)
อยู่ในคิว → ยกเลิก

กำลังแพ็ค → พร้อมรับ
พร้อมรับ → รับแล้ว

# จาก packing / ready_for_pickup / picked_up → ยกเลิก = ห้าม
```

## Cancel rules
- ลูกค้าหรือแอดมินยกเลิกได้เมื่อสถานะยัง**ก่อน** `กำลังแพ็ค`
- อนุญาตยกเลิกจาก: รอชำระ, รอตรวจสลิป, ปฏิเสธสลิป, อยู่ในคิว
- หลังเข้า `กำลังแพ็ค` / `พร้อมรับ` / `รับแล้ว` = ยกเลิกไม่ได้

## Money on cancel (v1 lock)
- ยังไม่โอน/ยังไม่อนุมัติสลิป: ไม่มีเงินเข้า → ไม่ต้องคืนอัตโนมัติ
- โอนแล้วและอนุมัติแล้ว (อยู่ในคิว) แล้วยกเลิก: **แอดมินจัดการคืนเงินด้วยมือใน v1** — ไม่มี auto-refund ในระบบ
- มัดจำ: คืนตาม UC-DEP เมื่อบันทึกคืนลัง (แยกจากยกเลิกออเดอร์ถ้าลังยังไม่งาน)

## Slip reject loop
- reject **ต้องมีเหตุผล** · แสดงบนบัตรคิว
- ลูกค้าอัปสลิปใหม่จากบัตรคิวได้ → กลับ `รอตรวจสลิป`
- ทำซ้ำได้จนกว่าจะ approve หรือยกเลิกตามกติกา
