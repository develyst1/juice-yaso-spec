# Scope — Juice Yaso v1

## In
- ร้านน้ำเกร็ดหิมะ · **รับที่ร้าน** (ไม่ส่งใน v1)
- ลูกค้า**ไม่มี login** · หน้าแรก = หน้าสั่ง
- สั่งลัง/รส (ปนได้) · บังคับชื่อ+เบอร์ก่อนชำระ · ได้บัตรคิว
- ชำระด้วย QR หรือเลขบัญชี + แนบสลิป · แอดมินไลน์ approve/reject
- Track / ยกเลิกด้วยบัตรคิว
- ราคาขายส่ง + มัดจำลัง + config ส่วนลด + config ช่องทางโอน

## Out (v1)
- ฟีเจอร์ส่งของ (phase หลัง; พื้นที่ส่งมีแค่ยโสธรแต่ยังไม่ทำ)
- ดูออเดอร์เก่าโดยไม่มีบัตรคิวปัจจุบัน
- Login / สมัครลูกค้า
- คิดราคาตลาดขายต่อ ~9 บาทในแอป
- Connection string / deploy / secret
- Auto-refund อัตโนมัติหลังยกเลิกเมื่อโอนแล้วแล้ว (v1 = แอดมินจัดการนอก/ด้วยมือ — ดู statuses)
