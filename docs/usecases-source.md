# Juice Yaso v1 — Use cases (Porter)
สถานะ: ready for Sober lock + push | ASK ME ปิดแล้ว

## ขอบเขต v1
- ร้านน้ำเกร็ดหิมะ · **รับที่ร้าน** (ฟีเจอร์ส่ง = phase หลัง ไม่ทำใน v1)
- ลูกค้าไม่ login · หน้าแรก = หน้าสั่ง
- สัญญาบน `juice-yaso-spec` · รอบนี้ห้าม scaffold front/back
- นอกขอบเขต: ส่งของ, ดูออเดอร์เก่า, login ลูกค้า, ราคาตลาดขายต่อ ~9, connection string/deploy

## กติกาที่ล็อกแล้ว
- ราคาขายส่ง 5 บาท/แก้ว; แก้วรวม > 100 → 4.5 บาท/แก้ว ทั้งออเดอร์ (threshold/ราคาแอดมินปรับได้; ใช้กับออเดอร์ใหม่เท่านั้น)
- ลังโฟม 30 / 50 / 60 / 100 · สั่งหลายลังได้
- มัดจำ: 30→50, 50→90, 60→90, 100→150 ต่อลัง · คืนเมื่อบันทึกคืนลังแล้ว
- รส: ส้ม องุ่น โกโก้ ลิ้นจี่ บลูเบอร์รี่ · **ออเดอร์เดียวปนหลายรสได้** · สีหลักส้ม
- ก่อนชำระบังคับ **ชื่อ + เบอร์**
- ชำระ: สแกน QR หรือโอนเลขบัญชี · แนบสลิป · รอตรวจได้ถึง ~1 ชม. · แอดมินอัปรูป QR / แก้เลขบัญชี+ชื่อธนาคารได้เสมอ
- แอดมินไลน์ approve/reject · reject ต้องมีเหตุผล · **หลังปฏิเสธสลิป อัปใหม่จากบัตรคิวได้ → กลับรอตรวจสลิป**
- ยกเลิกได้**ก่อน**สถานะกำลังแพ็ค (ลูกค้าหรือแอดมิน)
- ไม่มีระบบดูออเดอร์เก่าใน v1 · track ด้วยบัตรคิวเท่านั้น

## สถานะออเดอร์ v1 (LOCKED enum)
1. รอชำระ — ได้บัตรคิว ยังไม่ส่งสลิป
2. รอตรวจสลิป — อัปสลิปแล้ว รอแอดมิน
3. ปฏิเสธสลิป — reject มีเหตุผล; อัปสลิปใหม่ได้ → กลับข้อ 2
4. อยู่ในคิว — อนุมัติแล้ว รอแพ็ค
5. กำลังแพ็ค — ยกเลิกไม่ได้แล้ว (~30 นาที)
6. พร้อมรับ — แพ็คเสร็จ รอลูกค้ามารับที่ร้าน
7. รับแล้ว — ปิดออเดอร์
8. ยกเลิก — ยกเลิกก่อนกำลังแพ็ค

## Use cases v1

### UC-CUS-01 สั่งจากหน้าแรก (ไม่ login)
Actor: ลูกค้า
Main: เปิดหน้าแรก → เลือกลัง/จำนวน → เลือกรส (ปนได้) → กรอกชื่อ+เบอร์ → เห็นยอดสินค้า+มัดจำ → ยืนยัน → ได้บัตรคิวสถานะรอชำระ
DoD: ไม่ login; บังคับชื่อ+เบอร์; ได้บัตรคิว

### UC-CUS-02 คิดราคาขายส่งและส่วนลดรวม
Rule: 5 บาท/แก้ว; >100 → 4.5; config แอดมิน; ใช้กับออเดอร์ใหม่เท่านั้น
DoD: ยอดก่อนยืนยันตรงกติกา

### UC-CUS-03 คิดมัดจำลัง
Rule: ตามตารางมัดจำ · รวมหลายลัง · แยกจากราคาน้ำ
DoD: แสดงยอดมัดจำชัด

### UC-CUS-04 ได้บัตรคิวรอชำระ
DoD: บัตรคิวอ้างอิงออเดอร์; สถานะเริ่ม = รอชำระ; ใช้ชำระ/อัปสลิป/track/ยกเลิกได้

### UC-CUS-05 ชำระด้วย QR หรือเลขบัญชี + อัปสลิป
Main: จากบัตรคิวเห็น QR/เลขบัญชี+ชื่อธนาคาร → โอน → อัปสลิป → สถานะรอตรวจสลิป
DoD: ช่องทางชำระมาจาก config แอดมิน; อัปสลิปได้

### UC-CUS-05b อัปสลิปใหม่หลังถูกปฏิเสธ
Main: สถานะปฏิเสธสลิป (+เหตุผล) → อัปสลิปใหม่จากบัตรคิว → กลับรอตรวจสลิป
DoD: ทำซ้ำได้จนกว่าจะอนุมัติหรือยกเลิกตามกติกา

### UC-CUS-06 ติดตามสถานะด้วยบัตรคิว
DoD: ไม่ login ก็เห็นสถานะปัจจุบันจากชุด enum ด้านบน

### UC-CUS-07 ยกเลิกออเดอร์
Rule: ยกเลิกได้เมื่อสถานะยังไม่ใช่กำลังแพ็ค / พร้อมรับ / รับแล้ว (ตัดก่อนกำลังแพ็ค)
DoD: หลังยกเลิกสถานะ = ยกเลิก; มัดจำ/เงินตามที่ Sober ล็อกสัญญาคืน (ถ้าระบุ)

### UC-ADM-01 อนุมัติ/ปฏิเสธสลิปผ่านไลน์
Rule: reject ต้องมีเหตุผล · approve → อยู่ในคิว
DoD: ผลสะท้อนบนบัตรคิว

### UC-ADM-02 ปรับเกณฑ์ส่วนลดรวม
DoD: config ไม่แก้โค้ด; มีผลออเดอร์ใหม่

### UC-ADM-03 จัดการช่องทางโอน
DoD: แอดมินอัปรูป QR ใหม่ + แก้เลขบัญชี + ชื่อธนาคาร ได้เสมอ

### UC-ADM-04 เลื่อนสถานะแพ็ค/พร้อมรับ/รับแล้ว
DoD: อยู่ในคิว → กำลังแพ็ค → พร้อมรับ → รับแล้ว ตามโฟลว์ร้าน

### UC-DEP-01 คืนลังและคืนมัดจำ
DoD: คืนมัดจำได้เมื่อบันทึกคืนลังแล้ว
